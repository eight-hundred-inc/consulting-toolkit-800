# reference-decks — 参照 pptx の配備ディレクトリ

デザインの見本にする pptx を**このディレクトリに置く**。スキルは起動のたびに
ここを再帰的に走査し、見つかった `.pptx` / `.potx` を **すべて** 解析対象にする。

```
reference-decks/
├── README.md
├── 提案書_標準.pptx        ← 置くだけで参照対象になる
├── 報告書_標準.pptx
└── archive/一次提案.pptx   ← サブディレクトリも対象
```

## ルール

- 対象拡張子は `.pptx` と `.potx`。Excel の一時ファイル（`~$` 始まり）は自動で除外される。
- ファイルを追加・削除したら、次回の解析（`analyze_references.py`）に自動で反映される。
  スクリプト側の設定変更は不要。
- **テンプレートに使う 1 本**は、解析結果を見てスキルが選ぶ（またはユーザーが指定する）。
  残りのデッキは、レイアウト・図版・配色の語彙を学ぶ材料として参照される。
- クライアント固有の機微情報を含むデッキをコミットしないこと。共有したくないものは
  ローカルにだけ置き、`analyze_references.py --decks <別のパス>` で外部ディレクトリを指す。

## 確認コマンド

```bash
python3 ../scripts/analyze_references.py --outdir /tmp/spec
```

参照 pptx が 1 件も無い場合、スクリプトは終了コード 3 とエラーメッセージを返す。
