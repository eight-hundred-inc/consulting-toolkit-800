# SLIDE-PATTERN-issue-tree-dark-box-subcards

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。スライドマスター（branded-pptx のマスター定義 / html-artifact のテーマ）と組み合わせて使うことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・フッター・装飾はスライドマスターで定義されるため、このファイルには含みません。プレビュー .html は生成当時の見本であり非規範。見た目は選択マスターが決めます。

## Overview

**パターン名：** issue-tree-dark-box-subcards
**概要：** 「大きな問い（大論点）」を左のダーク背景ブロックに、それを構成する複数の「具体的な下位の問い（小論点）」を右側の軽量カードとして縦に積む、論点の階層構造を示すリスト。
**適したシーン：** プロジェクトで検討すべき論点の整理、調査の問いの構造化、ディスカッション資料で「今回検討すべきこと」を大→小の階層で提示する場面。
**対応する図解指名：** 論点ツリー／論点整理／イシューツリー
**下流実装ヒント：** html-artifact: 行グループ化されたリスト（左に強調ラベルボックス、右にサブカード縦積み）／pptx: 左に濃色矩形、右に罫線区切りの小カードを縦に配置

## Structure（構造）

コンテンツエリアを縦に2〜4個の「大論点グループ」に積む。各グループは左に固定幅のダーク背景ブロック（大論点＝1つの大きな問いを3〜4行で記述）、右にそのグループに属する1〜3個の軽量なサブカード（小論点＝具体的な下位の問い）を縦に積んで構成する。大論点ブロックの高さは、配下の小論点カードの合計高さに合わせて伸縮する。

    layout: issue-tree-dark-box-subcards
    zones:
      - role: major-issue-block   # ×2〜4（縦に積む）
        width: 28%
        content: 大論点ラベル＋大きな問い（3〜4行）。ダーク背景で強調し、配下の小論点カード群と高さを揃える
      - role: sub-issue-list
        width: 72%
        content: 小論点カード ×1〜3（各カードはラベル＋短い問い1行）。縦に積む
    reading_order: 上 → 下（大論点グループ単位）。各グループ内は 左（大論点）→ 右（小論点群、上から下）
    notes: 大論点の数（グループ数）と各グループの小論点数はソース資料に応じて増減可。大論点ブロックと小論点カード群は行単位で高さを揃える。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 大論点ラベル＋問い文 | 各グループの左（ダーク背景） | そのグループ全体を貫く中心的な問いを提示する |
| 小論点カード | 各グループの右、縦に積む | 大論点を分解した具体的な下位の問いを1件ずつ示す |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-issue-tree-dark-box-subcardsのレイアウトで、3つの大論点を縦に並べ、それぞれに1〜3個の小論点を紐づけてください。大論点は1〜2文の問い、小論点は1行程度の具体的な問いにしてください。デザインはスライドマスターに従ってください。」

**注意点：**
- 大論点は2〜4個が目安。5個以上になると1件あたりの高さが窮屈になるため、統合するか2スライドに分ける。
- 小論点は大論点を確実に分解する下位の問いにする。大論点と無関係な問いを並べない。
- 仮説や回答まで踏み込みたい場合は、より詳細な `SLIDE-PATTERN-issue-hypothesis-mapping-table` を検討する。
