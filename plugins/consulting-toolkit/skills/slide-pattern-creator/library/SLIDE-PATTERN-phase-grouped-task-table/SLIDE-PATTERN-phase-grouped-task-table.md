# SLIDE-PATTERN-phase-grouped-task-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。スライドマスター（branded-pptx のマスター定義 / html-artifact のテーマ）と組み合わせて使うことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・フッター・装飾はスライドマスターで定義されるため、このファイルには含みません。プレビュー .html は生成当時の見本であり非規範。見た目は選択マスターが決めます。

## Overview

**パターン名：** phase-grouped-task-table
**概要：** 「フェーズ」「タスク番号＋タスク名」「主な内容（または納品物）」の3列で構成する表。同一フェーズに属する複数のタスク行を左列でグループ化し、縦線・罫線でフェーズの区切りを視覚化する。
**適したシーン：** プロジェクトのタスク一覧、フェーズ別の納品物一覧、WBS（Work Breakdown Structure）の提示。複数フェーズ×複数タスクを1枚で網羅的に見せたい場面。
**対応する図解指名：** フェーズ別タスク表／WBS
**下流実装ヒント：** html-artifact: Structured Table（フェーズ列をグループ結合）／pptx: 表＋左列セル結合、フェーズ境界に縦線装飾

## Structure（構造）

コンテンツエリアを3列の表にする。左列はフェーズ名（＋対応論点等の補足）で、同一フェーズに属するタスク行数ぶんセル結合または縦線でまとめる。中央列はタスク番号とタスク名を行ごとに記載する。右列はそのタスクの主な内容、または納品物を箇条書きで記載する。

    layout: phase-grouped-task-table
    zones:
      - role: phase-column
        width: 20%
        content: フェーズ名＋補足（対応論点等）。複数タスク行にまたがってグループ化し、縦線または罫線でまとめる
      - role: task-column
        width: 12%
        content: タスク番号＋タスク名（行ごと）
      - role: detail-column
        width: 68%
        content: 主な内容、または納品物（行ごと、箇条書き1〜3項目）
    reading_order: 上から下（フェーズグループ単位）。各グループ内は上から下（タスク番号順）
    notes: 同一フェーズに属するタスクは罫線でグループ化し、フェーズ列はセル結合または縦線でまとめる。フェーズ数3〜4、フェーズあたりタスク数2〜3が目安。右列の内容は「主な内容」「納品物」など目的に応じて差し替え可能。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| フェーズ名 | 左列 | 複数タスクを束ねる大きな区切り（フェーズ1〜3等） |
| 対応論点（任意） | フェーズ名の下 | そのフェーズがどの論点・目的に対応するかの注記 |
| タスク番号 | 中央列 | 1-1, 1-2等の通し番号 |
| タスク名 | タスク番号の右 | 実施内容の名称 |
| 内容／納品物 | 右列 | タスクの具体的な中身、または成果物の説明（箇条書き） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-phase-grouped-task-tableのレイアウトで、3つのフェーズそれぞれに2〜3個のタスクを紐づけ、各タスクの主な内容（または納品物）を箇条書きで入れてください。フェーズ列は縦線でグループ化してください。デザインはスライドマスターに従ってください。」

**注意点：**
- フェーズ数は3〜4、フェーズあたりタスク数は2〜3が目安。行数が増えすぎると1行あたりの高さが窮屈になる。
- タスク一覧と納品物一覧など、右列の意味を変えて同じ骨格を複数スライドで使い回せる（フェーズ・タスク番号は共通のまま）。
- タスク名は動詞で終わる実施内容（〜の可視化、〜の策定 等）に統一する。
