## Overview

**パターン名：** chevron-phase-gantt-timeline
**概要：** 上部に3つのシェブロン帯（フェーズ見出し）を横並びで配置し、その下に週または月単位の目盛りを持つ時間軸、マイルストーン（▼マーカー）、時系列に配置されたテキスト吹き出しを組み合わせたロードマップ。表形式のガントチャートと異なり、マイルストーンとタスク説明を自由配置の吹き出しで示す。
**適したシーン：** プロジェクトスケジュールの提示、キックオフから完了までのロードマップ共有、大きなフェーズ区分と週次の重要イベントを同時に見せたいスケジュールスライド。
**対応する図解指名：** スケジュール／ロードマップ／ガントロードマップ
**下流実装ヒント：** html-artifact: 概念フロー（横シェブロン）＋タイムライン軸のネスト構成／pptx: シェブロンshape＋横線＋テキストボックス自由配置

## Structure（構造）

コンテンツエリア最上段に3つのシェブロン帯（フェーズ名、左から右へ進行）を横並びで配置する。その下に週（または月）単位の目盛りラベルを時系列に並べたスケール行を置く。スケールの下に、フェーズの節目となる週にマイルストーン（▼マーカー＋ラベル）を配置し、そこから下に伸びる縦線とテキスト吹き出し（実施タスクの箇条書き）を時系列に左から右へ並べる。吹き出しの縦位置はテキスト量に応じて自由に調整してよい。

    layout: chevron-phase-gantt-timeline
    zones:
      - role: phase-header-band
        content: シェブロン帯 ×3（フェーズ名、上部に横並び、左から右へ進行）
      - role: week-scale
        content: 週または月の目盛りラベル（フェーズ帯の下、時系列に横並び）
      - role: milestone-marker
        content: マイルストーン（▼マーカー＋ラベル、目盛り上の特定週に配置）
      - role: timeline-callout
        content: 各マイルストーンから下に伸びる縦線＋テキスト吹き出し（箇条書き2〜3項目）。時系列に左から右へ配置し、重ならないよう縦位置をずらしてよい
    reading_order: 上（フェーズ帯）→ 中（週目盛り）→ 下（マイルストーン・吹き出しを時系列に左から右）
    notes: フェーズ帯は大まかな期間区分、その下の目盛りとマイルストーンは実際の週次スケジュールを表す。既存の `SLIDE-PATTERN-timeline-gantt`（タスク×時間軸の表形式ガント）とは異なり、本パターンはタスクバーの表を持たず、フェーズ見出し＋自由配置の吹き出しで構成する点が特徴。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| フェーズ帯 | 最上段 | 大まかな期間区分の名称（フェーズ1／2／3） |
| 週目盛り | フェーズ帯の下 | 1週間単位の時間軸ラベル |
| マイルストーン▼ | 目盛り上の特定週 | キックオフ・報告会等の重要な区切り日を示す |
| コールアウト吹き出し | マイルストーンの下 | その時点までに実施するタスクを箇条書きで説明する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-chevron-phase-gantt-timelineのレイアウトで、3つのフェーズのシェブロン帯を上部に配置し、その下に週単位の時間軸とマイルストーン（キックオフ・中間報告・完了報告）を置いてください。各マイルストーンの下に実施タスクを吹き出しで示してください。デザインはスライドマスターに従ってください。」

**注意点：**
- マイルストーンは3〜4個程度に絞る。増やしすぎると吹き出しが重なり可読性が下がる。
- 吹き出しの接続線は、上のマイルストーンとの対応が明確になるよう起点を揃える。
- タスクをバー（開始〜終了の帯）として厳密に表現したい場合は `SLIDE-PATTERN-timeline-gantt` を検討する。
