# SLIDE-PATTERN-label-rail-two-case-comparison

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。スライドマスター（branded-pptx のマスター定義 / html-artifact のテーマ）と組み合わせて使うことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・フッター・装飾はスライドマスターで定義されるため、このファイルには含みません。プレビュー .html は生成当時の見本であり非規範。見た目は選択マスターが決めます。

## Overview

**パターン名：** label-rail-two-case-comparison
**概要：** コンテンツエリアを左右2分割し、各半分に1つの事例を配置する。各事例の内部にはさらに「背景・目的」「概要」の左固定幅ラベルタブと本文（テキスト・画像）が縦に並ぶ、2階層構造の事例比較パターン。
**適したシーン：** 先行事例・競合事例を2件並べて比較検討する場面。関連事例紹介、ベンチマーク提示、提案の裏付けとなる他社事例の並列表示。
**対応する図解指名：** 事例比較（2社）
**下流実装ヒント：** html-artifact: 2カラム×（ラベル帯＋本文）のネスト構成／pptx: 2カラム、各カラム内に縦長ラベル矩形×2

## Structure（構造）

コンテンツエリアを左右50:50に分割し、各半分を1つの事例に割り当てる。各事例の内部は、上部に事例見出し（企業名＋取組み名）、その下に「背景・目的」行（左に固定幅ラベルタブ、右に箇条書き）、続けて「概要」行（左に同幅のラベルタブ、右にテキスト・画像）を縦に積み、最下部に出典リンクを置く。左右の事例は同じ内部構成で揃える。

    layout: label-rail-two-case-comparison
    zones:
      - role: case-column   # ×2（左／右）
        width: 50%
        elements:
          - role: case-heading
            content: 事例企業名＋取組み名（見出し）
          - role: background-row
            content: 左に固定幅ラベルタブ（背景・目的）＋右に箇条書き2〜4項目
          - role: overview-row
            content: 左に固定幅ラベルタブ（概要）＋右にテキスト・画像（画像は任意）
          - role: source-note
            content: 出典リンク（各カラム最下部、小さいテキスト）
    reading_order: 左事例（見出し → 背景・目的 → 概要 → 出典）→ 右事例（同順）
    notes: 左右の事例は同じ内部構成（見出し→背景・目的→概要→出典）で揃える。概要行は画像を含む場合とテキストのみの場合がある。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 事例見出し | 各カラム上部 | 企業名＋取組みの名称を示す |
| 背景・目的ラベルタブ | 各カラム内、背景行の左 | そのセクションが背景・目的の説明であることを示す |
| 背景・目的テキスト | 背景行の右 | 課題認識・導入の狙いを箇条書きで記述する |
| 概要ラベルタブ | 各カラム内、概要行の左 | そのセクションが取組みの具体的内容であることを示す |
| 概要テキスト＋画像 | 概要行の右 | 施策の詳細説明とスクリーンショット・図（任意）を示す |
| 出典リンク | 各カラム最下部 | 引用元を明記する（原則8：引用の忠実性） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-label-rail-two-case-comparisonのレイアウトで、2社の関連事例を左右に並べてください。各事例は見出し、背景・目的（箇条書き2〜3項目）、概要（テキストと画像プレースホルダ）、出典の順で構成してください。デザインはスライドマスターに従ってください。」

**注意点：**
- 1スライド＝2事例。3件以上を比較したい場合はカード並列など別パターンを検討する。
- 左右の情報量・ラベルタブの高さは揃え、対比としてのバランスを保つ。
- 出典は必ず明記し、原典に忠実に引用する（原則8：引用の忠実性）。
