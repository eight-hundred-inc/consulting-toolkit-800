## Overview

**パターン名：** label-rail-flow-outcome
**概要：** 「課題」「ソリューション」「期待効果」を縦3段に積み、各段の左端に固定幅のラベルタブを置いて区分を示す。ソリューション段の内容部分はさらに3ステップのシェブロンフロー（見出し＋配下の箇条書き）で構成される、課題解決策を1枚で完結させるパターン。
**適したシーン：** 具体的なソリューション・打ち手の提案スライド。AI活用施策やDX施策の詳細説明など、「課題→解決の道筋（複数ステップ）→得られる効果」を1枚に凝縮して見せたい場面。
**対応する図解指名：** 課題解決フロー／ソリューション詳細
**下流実装ヒント：** html-artifact: 左ラベル帯＋概念フロー（横3ステップ）のネスト構成／pptx: 左に縦長ラベル矩形×3、中段に矢印（シェブロン）shape×3

## Structure（構造）

コンテンツエリアを縦3段（課題／ソリューション／期待効果）に積む。各段は左に固定幅（同一幅）のラベルタブを置き、右側にその段の内容を展開する。中段（ソリューション）の内容部分だけは横方向にさらに分割され、3つのシェブロン見出し（左→右へ進む段階）とその配下の箇条書き詳細で構成される。

    layout: label-rail-flow-outcome
    zones:
      - role: problem-row
        content: 左に固定幅ラベルタブ（課題）＋右に課題文（1〜3行）
      - role: solution-row
        content: 左に固定幅ラベルタブ（ソリューション）＋右に3ステップのシェブロンフロー（ステップ見出し×3、各ステップ配下に箇条書き2〜3項目）
      - role: outcome-row
        content: 左に固定幅ラベルタブ（期待効果）＋右にチェックマーク付き箇条書き2〜3項目
    reading_order: 上から下（課題 → ソリューション → 期待効果）。ソリューション行内は左から右（ステップ1 → 2 → 3）
    notes: 3行のラベルタブ幅は揃える。ソリューション行のステップ数は3が基本（2〜4で可変）。行間は罫線・点線などで区切る。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 課題ラベルタブ | 最上段・左 | このセクションが課題提示であることを示す |
| 課題文 | 最上段・右 | 現状のペインポイントを1〜3行で記述する |
| ソリューションラベルタブ | 中段・左 | このセクションが解決策であることを示す |
| ステップ見出し（×3） | 中段・右上、横並び | 解決策を構成する段階の名称 |
| ステップ詳細（×3） | 各ステップ見出しの下 | そのステップの具体的な取り組み内容（箇条書き2〜3項目） |
| 期待効果ラベルタブ | 下段・左 | このセクションが得られる効果であることを示す |
| 効果リスト | 下段・右 | 達成される効果・数値目標を箇条書きで列挙する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-label-rail-flow-outcomeのレイアウトで、課題を1〜2文、ソリューションを3ステップのフロー（各ステップに箇条書き2〜3項目）、期待効果を2〜3項目のチェックリストで入れてください。デザインはスライドマスターに従ってください。」

**注意点：**
- 3段のラベルタブは幅・高さの起点を揃え、視覚的な帯として統一する。
- ソリューションのステップは時系列または論理的な順序（例：データ化→学習→活用）にする。単なる並列項目にしない。
- 期待効果は課題・ソリューションと対応させ、可能な限り定量目標（%・日数等）を含める。
