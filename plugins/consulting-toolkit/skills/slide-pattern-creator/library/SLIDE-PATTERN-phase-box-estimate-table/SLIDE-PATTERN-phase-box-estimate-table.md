# SLIDE-PATTERN-phase-box-estimate-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。スライドマスター（branded-pptx のマスター定義 / html-artifact のテーマ）と組み合わせて使うことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・フッター・装飾はスライドマスターで定義されるため、このファイルには含みません。プレビュー .html は生成当時の見本であり非規範。見た目は選択マスターが決めます。

## Overview

**パターン名：** phase-box-estimate-table
**概要：** 「フェーズ（角丸ボックスで強調）」「期間」「主な支援内容」「金額」の4列で構成する見積りテーブル。フェーズを主語に1行1フェーズで並べ、金額は大きな数字で強調する。表の上部に前提条件を任意で添えられる。
**適したシーン：** 提案書における見積り提示、フェーズ別の価格内訳表示、契約前の概算費用共有。
**対応する図解指名：** 見積りテーブル／フェーズ別料金表
**下流実装ヒント：** html-artifact: Structured Table（左列を角丸バッジ化、金額列を強調表示）／pptx: 表＋左列角丸矩形装飾

## Structure（構造）

コンテンツエリア上部に任意で前提条件ブロック（枠囲みの箇条書き）を置く。その下に4列の表を配置し、列は「フェーズ（角丸ボックスで強調）」「期間（数字を大きく表示）」「主な支援内容（箇条書き）」「金額（数字を大きく表示、補足あり）」の順。1行＝1フェーズとし、フェーズ数ぶんの行を縦に並べる。

    layout: phase-box-estimate-table
    zones:
      - role: precondition-note
        content: 前提条件（枠囲みの箇条書き、テーブル上部、任意）
      - role: phase-box-column
        width: 22%
        content: フェーズ名（角丸ボックスで強調、1行1フェーズ）
      - role: duration-column
        width: 12%
        content: 期間（大きめの数字表示、例：3ヶ月）
      - role: content-column
        width: 44%
        content: 主な支援内容（箇条書き2〜3項目）
      - role: price-column
        width: 22%
        content: 金額（大きな数字＋補足の月額表示）
    reading_order: 上（前提条件）→ 下（フェーズごとに上から下、各行は左から右：フェーズ → 期間 → 内容 → 金額）
    notes: フェーズ数3〜4が目安。金額には税別等の注記を添える。前提条件ブロックは見積りの適用条件が明確な場合のみ置く。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 前提条件 | テーブル上部の枠（任意） | 見積りの適用条件・スコープを明記する |
| フェーズボックス | 各行左端 | フェーズ名を角丸ボックスで強調する |
| 期間 | 各行、フェーズの右 | そのフェーズにかかる期間の目安を示す |
| 支援内容 | 各行中央 | フェーズで提供する支援の具体的内容を箇条書きで示す |
| 金額 | 各行右端 | 概算見積り金額を大きな数字で強調し、月額等を補足する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-phase-box-estimate-tableのレイアウトで、3つのフェーズそれぞれに期間・主な支援内容（箇条書き2〜3項目）・概算金額を入れてください。表の上部に前提条件を3行程度で添えてください。デザインはスライドマスターに従ってください。」

**注意点：**
- フェーズ数は3〜4が目安。多すぎると1行あたりの情報が窮屈になる。
- 金額は視認性を優先し、他の列より大きな文字サイズで強調する。
- 前提条件を書く場合は見積りのスコープ（含む/含まない）を明確にし、後工程での認識齟齬を防ぐ。
