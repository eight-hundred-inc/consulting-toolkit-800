# SLIDE-PATTERN-issue-hypothesis-mapping-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。スライドマスター（branded-pptx のマスター定義 / html-artifact のテーマ）と組み合わせて使うことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・フッター・装飾はスライドマスターで定義されるため、このファイルには含みません。プレビュー .html は生成当時の見本であり非規範。見た目は選択マスターが決めます。

## Overview

**パターン名：** issue-hypothesis-mapping-table
**概要：** 「大論点」「大論点への仮説要約」「小論点」「小論点への仮説詳細」の4カラムを、大論点ごとにグループ化して並べる表。論点の階層構造と、それぞれに対する現時点の仮説（仮の答え）を1枚で対応づけて示す。
**適したシーン：** 初期仮説の提示、論点整理と仮説を対応づけて見せたい調査・ディスカッション資料。論点だけでなく「今の時点でどう考えているか」まで踏み込みたい場面。
**対応する図解指名：** 論点×仮説マッピング／仮説マップ
**下流実装ヒント：** html-artifact: Structured Table（1・2列をグループ結合）／pptx: 表＋左2列のセル結合、グループごとに罫線区切り

## Structure（構造）

コンテンツエリアを4列の表にする。列は「大論点（左端、ダーク背景）」「大論点への仮説要約」「小論点ラベル」「小論点への仮説詳細」の順。大論点と仮説要約の2列は、その大論点に属する小論点の行数ぶんセル結合し、行が進むごとに小論点ラベルと仮説詳細だけが切り替わる。大論点グループは罫線で区切る。

    layout: issue-hypothesis-mapping-table
    zones:
      - role: major-issue-block   # 大論点ごとにグループ化、行結合
        width: 14%
        content: 大論点ラベル＋問い文（ダーク背景、グループの行数ぶん結合）
      - role: major-hypothesis    # 大論点ごとにグループ化、行結合
        width: 16%
        content: その大論点に対する仮説の要約（グループの行数ぶん結合）
      - role: sub-issue-label
        width: 10%
        content: 小論点ラベル（行ごと、例：小論点①-1）
      - role: sub-hypothesis-detail
        width: 60%
        content: 小論点に対する仮説の詳細説明（行ごと、2〜4行）
    reading_order: 上から下（大論点グループ単位）。各グループ内は左から右（大論点 → 仮説要約 → 小論点ラベル → 仮説詳細）を行ごとに読む
    notes: 大論点ブロックと仮説要約ブロックは、そのグループに属する小論点の行数ぶんセル結合する。小論点数は大論点1つあたり1〜3行が目安。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 大論点ボックス | 左端、グループ結合 | 検討すべき大きな問いを提示する |
| 仮説要約 | 大論点の右、グループ結合 | 大論点に対する現時点の仮の答えを要約する |
| 小論点ラベル | 各行の左寄り | 大論点を分解した具体的な問いの通し番号・短文 |
| 仮説詳細 | 各行の右、最大幅 | 小論点に対する仮説の具体的内容（根拠・手法等）を記述する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-issue-hypothesis-mapping-tableのレイアウトで、3つの大論点それぞれに仮説要約を添え、配下に1〜3個の小論点と、それぞれの仮説詳細を入れてください。デザインはスライドマスターに従ってください。」

**注意点：**
- 仮説要約は大論点1つにつき1つ（簡潔な結論）、仮説詳細は小論点1つにつき1つ（具体的な根拠・手法）に役割を分ける。
- 仮説はあくまで初期仮説であることが伝わる書き方にする（断定を避け「〜と考えられる」「〜が最適解となり得る」等）。
- 論点構造のみを見せたく、仮説まで書く必要がない場合は `SLIDE-PATTERN-issue-tree-dark-box-subcards` を使う。
